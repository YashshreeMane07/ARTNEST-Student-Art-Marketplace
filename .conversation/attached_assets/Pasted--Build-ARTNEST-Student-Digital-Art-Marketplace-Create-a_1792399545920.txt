# Build ARTNEST — Student Digital Art Marketplace

Create a complete **frontend-only web application** called **ARTNEST**.

ARTNEST is a digital art marketplace designed specifically for **student creators**, where students can showcase, sell, collaborate, receive commissions, build portfolios and connect with buyers.

## IMPORTANT

Build **ONLY THE FRONTEND UI** for now.

Do NOT create:
- Backend
- Database
- APIs
- Authentication
- Real payment processing
- Real AI APIs

Use realistic **mock/sample data** so that every page looks functional and interactive.

The frontend should be structured so that a backend can easily be connected later.

---
