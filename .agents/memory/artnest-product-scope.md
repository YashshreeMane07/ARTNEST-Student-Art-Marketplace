---
name: ARTNEST product scope
description: User-stated audience and implementation scope for the ARTNEST marketplace.
---

ARTNEST is for student creators to showcase and sell digital artwork, connect with buyers, request commissions, collaborate, and build portfolios.

For the current release, the user explicitly requested a frontend-only prototype: do not add a backend, database, API, authentication, real payment processing, or live AI features unless the user asks.

**Why:** the user asked to establish the complete UI and realistic mock interactions before adding production services.

**How to apply:** keep demo data and interactions local to the browser for this release; treat server-side features and real payments as future work that requires an explicit scope change.
